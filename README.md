3D Clock

A desktop-based 3D Clock built with Three.js, Electron, and JavaScript.
This project displays a real-time 3D clock rendered in WebGL — designed to explore 3D visualization and animation inside an Electron environment.

// Clone the repository
git clone https://github.com/schvmq/3D-Clock.git
cd 3D-Clock

// Install dependencies
npm install electron three

// Start the app
npm start
